## Stack

- **Framework:** Next.js 16.4 (app router, RSC by default)
- **Styling:** CSS Modules + globals.css (Tailwind is imported but tokens are custom CSS vars driven by `lib/design-tokens.ts` and `components/TokenStyle.tsx`)
- **Fonts:** Geist Sans (body), IBM Plex Serif (headlines), KoreanFirst (custom variable typeface, WOFF2 at `/fonts/KoreanFirst-VF.woff2`)
- **Icons:** lucide-react

## Key architecture

- `lib/design-tokens.ts` → design token definitions (CSS vars). TokenStyle renders them into `<head>`.
- `components/effects/water-engine.js` → site-wide water ripple simulation. Self-contained vanilla JS, inlined via `<script>` by `components/effects/WaterRipple.tsx`. Uses SVG displacement filter on Chromium, canvas fallback elsewhere.
  - `data-lily` elements drift when cursor passes (lily-pad behaviour)
  - `data-no-ripple` elements suppress ripple spawning
  - `--ripple-strength` token controls bend intensity (0 = off)
  - `--card-float` token controls lily drift distance
- `components/ui/SectionIntro.tsx` → page hero/section headers. Two layouts: `"split"` (two-column, default) and `"stacked"` (vertical, used on home page).
- `lib/projects.ts` → project card data. `components/ProjectGrid.tsx` renders them.
- `lib/about.ts` → About page content (experience rows, etc.).
- `components/study/*` → case study layout system.
- `app/playground/koreanfirst/page.tsx` → KoreanFirst type tester page.

## Design tokens (key ones)

| Token | Default | Notes |
|---|---|---|
| `--bg` | white | Page background |
| `--ink` | near-black | Text colour |
| `--ink-soft` | grey | Secondary text |
| `--line` | light grey | Borders/rules |
| `--space-page-top` | 96px | Gap above page titles |
| `--space-section` | 64px | Under intros, between sections |
| `--ripple-strength` | 16 | Ripple bend amount (0 = off) |
| `--card-float` | 2px | Lily-pad drift distance |
